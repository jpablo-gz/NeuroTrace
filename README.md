# NeuroTrace

NeuroTrace is a C++ project that aims to recognize handwritten digits using a small neural network trained from scratch.

The goal is to let users draw a number from 0 to 9 in a simple window and see what the network predicts. The project will also explore how the network learns from examples of handwritten digits.

## Project goals

- Build and train a small neural network in C++.
- Recognize digits drawn by the user.
- Show the predicted digit and the network’s results for the other possibilities.
- Provide a simple, visual way to explore how a neural network recognizes handwriting.
